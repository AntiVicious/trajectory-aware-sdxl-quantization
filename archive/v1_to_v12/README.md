# Archive: Variants V1–V12

Scripts from the twelve static, per-layer quantization variants tried before
the trajectory-aware framework: ternary mid-blocks, SmoothQuant, distillation,
LoRA recovery, timestep-aware LoRA and outlier preservation. The thesis
describes these variants and why they plateaued at a DreamSim of
about 0.18.

These scripts are kept as a record of that work and are not maintained. They
use the file paths of the original lab machine and are not covered by
[REPRODUCTION.md](../../REPRODUCTION.md); the reproducible pipeline is in
`src/`.
